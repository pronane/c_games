# motion_library_owned

Moves the project owner holds the rights to: Meshy Text to Motion clips made on the owner's paid plan (v11.41).
Licensed `LicenseRef-Owned-Meshy`, redistributable with this project; not CC0. The CC0 starter is `../motion_library/`.

* `mz_<pack>_<move>.json`: the clip on the shared skeleton (the record keeps the prompt).
* `src/meshy/<pack>/<move>.bvh` + `.task.json`: the file Meshy returned, for `forge.py meshy import --pack <pack>`.

Made with `forge.py meshy motion --pack gaelic` from the prompts in `../game_packs/meshy/`.
