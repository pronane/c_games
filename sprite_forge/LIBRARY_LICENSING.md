# Library and pack licensing

Sprite Forge Studio lets you use your own FBX/GLB characters and animations as templates, and share them as
`.sfpack` packs. This page explains what the Studio enforces and what you have to check yourself.
It is practical guidance, not legal advice.

## The licence record (every asset has one)
`library/<kind>/<name>/licence.json`. Edit it with `forge.py library licence NAME ...` or Library tab > Licence...

| field | meaning |
|---|---|
| `spdx` or `custom_text` | e.g. `CC0-1.0`, `CC-BY-4.0`, or the store's licence text / URL |
| `author` | who made it |
| `source_url` | where you got it |
| `redistribution` | `yes` / `no` / `unknown`. May it be passed on to other people as a file? |
| `attribution` | the credit line to show (required for CC-BY and similar) |
| `includes` | added automatically: clips retargeted from other assets, with their licences |
| `rights_override` | added only by an explicit "I own the rights" confirmation (who, when, statement) |

## What the Studio enforces
* **Local use is always allowed:** imports, builds, retargeting and exports for your own project.
* **`library pack` / Export pack refuses** any asset where:
  * the record is incomplete;
  * redistribution is `no` or `unknown`;
  * or it includes clips from such an asset.
* **The only way past the refusal** is `--i-own-the-rights NAME --by "Your Name"` (in the GUI: tick the box and
  type your name).
  * The name, the date and the statement are written into `pack.json` and shown to everyone who installs the
    pack.
  * It does not override `includes` from a non-redistributable source. Remove those clips with
    `forge.py library clips-drop NAME from:SOURCE`.
* **`library install` / Install pack:**
  * shows every asset's licence and installs nothing without `--accept-licences` (GUI: the acknowledgement
    tick box);
  * verifies a sha256 for every file;
  * refuses unsafe paths;
  * records where each asset came from.

## Third-party stores (terms differ and change: read them)
* **Mixamo (Adobe):** characters and animations are royalty-free to use in your own projects and games, but
  the raw files may not be redistributed (for example as an asset pack).
  * Keep Mixamo downloads at `redistribution = no`.
  * Clips retargeted from Mixamo are still Mixamo data, and the `includes` tracking keeps them out of packs.
  * Do not use the "I own the rights" confirmation for them.
  * Source: https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html
* **Unity Asset Store, Sketchfab, CGTrader, TurboSquid and others:** each has its own licence. Many allow use in
  a game but not redistributing the source files.
* **Creative Commons:** CC0 allows anything. CC-BY needs the attribution line. NC and ND variants restrict
  commercial use and changes.
* **If you are unsure,** set `redistribution = unknown`. The asset stays usable locally and stays out of packs.

* **Meshy:**
  * Free-plan output is owned by Meshy and licensed CC BY 4.0. Use it with the credit line (`--preset meshy-free`).
  * Paid-plan output belongs to you (`--preset meshy-paid` sets redistribution no; change it if you want to share).
  * Clips from Meshy's animation library are "Service Assets", so they stay out of packs by default.
  * Check the current terms: https://www.meshy.ai/terms-of-use
* **MakeHuman:**
  * The assets (base mesh, skeleton, weights, targets) are CC0, so characters made from them can be packed
    (`--preset makehuman`).
  * MakeHuman's program code is AGPL. The Studio does not include or run it.
  * v10.2 also uses MakeHuman's CC0 system assets (hair, eyebrows, eyelashes, eyes, skins, all morph targets),
    downloaded by `forge.py human --setup --full`, so looks made with `forge.py look` can be packed too.
  * MPFB2 (MakeHuman for Blender, GPL) is only used by the optional check `tools/mh_verify_blender.py`, run inside
    your own Blender. It is not shipped, and nothing it outputs goes into the characters.

## What we ship
* v7 equip samples (`library/outfits/sample_*`, `library/props/sample_*`): generated by `tools/make_equip_samples.py`, CC0 1.0.
* MakeHuman assets are NOT in the zip; `forge.py human --setup` downloads them.
* No third-party characters or animations.
* `packs/sfs_starter_cc0.sfpack` (installed in `library/`) is synthetic content generated by
  `tools/make_starter_library.py`. It is released under CC0 1.0.
