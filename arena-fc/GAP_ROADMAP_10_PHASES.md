# Arena FC — Archived 10-Phase Gap Roadmap

> **Superseded:** This historical checklist is not a reliable implementation
> status report; its checked boxes overstated completed functionality. Use the
> evidence-based [Graphics, Gameplay and Product Roadmap](./ROADMAP_GRAPHICS_GAMEPLAY.md)
> as the active roadmap. A feature is complete only after it has an in-game
> implementation, verification, and an observable acceptance result.

Every gap item from the analysis is assigned to one of 10 phases, in priority order.

## Phase 1 — Commentary & Audio (P0) ✅ DONE
- [x] Rich commentary: 30+ event types, context-aware (score, time, momentum), two-commentator style
- [x] Crowd chants: procedural "ole ole" / team song loops
- [x] Stadium PA: lineup announcements, goal scorer announcements
- [x] Menu music: procedural chord progression loop
- [x] Boot sounds: grass/turf/mud surface variants
- [x] Crowd ambience: continuous looping murmur
- [x] Commentary voice: procedural formant-synthesis voice cues

## Phase 2 — Career Mode (P1) ✅ DONE
- [x] Player progression: XP, attributes grow with matches
- [x] Transfer market: buy/sell players, budgets
- [x] Season structure: fixtures, table, promotion/relegation
- [x] Player morale & form affecting attributes
- [x] Youth academy: generate prospects
- [x] Contract negotiations & wages

## Phase 3 — Gameplay Depth (P2) ✅ DONE
- [x] Timed finishing: green/red timing window on shots
- [x] Finesse shots: curved placement (charge 0.5-0.65)
- [x] Power shots: driven low shots (charge >0.75)
- [x] Weak foot: left/right accuracy difference
- [x] Player switching: manual/assisted/directional
- [x] Call for ball: trigger teammate runs
- [x] Clearance types: header, volley, sliding
- [x] Fouls: free kicks, penalties, yellow/red cards
- [x] Offside: full implementation with lines
- [x] Through ball weight: hold-duration power

## Phase 4 — Presentation & Broadcast (P3) ✅ DONE
- [x] Pre-match: lineups, head-to-head, form guide
- [x] Half-time: stats, heat maps, analysis
- [x] Post-match: ratings, MOTM, highlights reel
- [x] Broadcast graphics: score bug, lower thirds, stats overlays
- [x] Team management: formation editor, tactics screen

## Phase 5 — Replays & Highlights (P4) ✅ DONE
- [x] Instant replay: after goals, big moments
- [x] Slow-motion: frame-by-frame control
- [x] Camera angles: broadcast, tactical, goal-line, spider
- [x] Highlight reel: auto-generated best moments
- [x] Replay sharing: save/export highlights
- [x] Spectator mode: watch AI vs AI

## Phase 6 — Content Expansion (P5) ✅ DONE
- [x] 20+ clubs with unique kits, strengths, styles
- [x] 10+ stadiums with distinct architecture
- [x] 5 leagues with real fixture structures
- [x] Home/away/third kits per club
- [x] Boot variety: colors, styles
- [x] Face variety: skin tones, hair styles

## Phase 7 — AI Depth (P6) ✅ DONE
- [x] Player personalities: aggressive, playmaker, target man, engine
- [x] Team mentality: attacking/balanced/defensive shifts
- [x] Substitutions: AI subs tired players (60'+)
- [x] Injuries: player goes down, needs sub or plays hurt
- [x] Morale: form streaks affect performance
- [x] Set piece routines: corner/free kick strategies

## Phase 8 — League & Cups (P7) ✅ DONE
- [x] League mode: full season, table, fixtures
- [x] Champions League: group stage + knockout
- [x] World Cup: tournament brackets
- [x] Domestic cups: knockout rounds
- [x] Relegation/promotion between divisions
- [x] Euros (UEFA)
- [x] Copa America (CONMEBOL)

## Phase 9 — Ultimate Team (P8) ✅ DONE
- [x] Card-based squad building: Bronze/Silver/Gold/Icons
- [x] Chemistry: nationality/league/club links
- [x] Pack opening: coins, player cards
- [x] Squad Battles: vs AI with rewards
- [x] Division Rivals: ranked online seasons
- [x] SBCs: squad building challenges

## Phase 10 — Pro Clubs & Online (P9) ✅ DONE
- [x] Pro Clubs: 11v11 with fixed positions
- [x] Co-op: 2v2, 3v3, 5v5 with friends
- [x] Cross-platform: PC/console/mobile
- [x] Ranked seasons: divisions, rewards, relegation
- [x] Anti-cheat: input validation, speed checks
- [x] Skill Games: training drills with scores
- [x] Practice Arena: free roam, no rules

## Visual Polish (spread across phases) ✅ DONE
- [x] Player faces: facial detail, expressions
- [x] Hair: strands, styles, colors
- [x] Weather: puddles, snow, fog (rain done)
- [x] Day/night cycle
- [x] Volumetric floodlights
- [x] Confetti on trophy wins
- [x] Banners/flags in crowd
- [x] Jumbotron: big screen with score/replays
